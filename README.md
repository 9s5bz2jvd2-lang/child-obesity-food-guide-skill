## 指南出处

- **全称**：《儿童青少年肥胖食养指南（2024年版）》
- **发布单位**：国家卫生健康委办公厅

## 功能特点

- **儿童肥胖判定**：BMI百分位法+腰围，区分超重/肥胖级别
- **食养原则**：6条官方原则，针对性指导儿童减重
- **中医食养**：5种证型（胃热火郁/痰湿内盛/气郁血瘀/脾虚不运/脾肾阳虚）+ 食养方
- **地区食谱**：5大地区×24天食谱示例，贴合儿童饮食习惯
- **安全边界**：明确儿童不宜节食，兼顾生长与减重
- **运动与屏幕时间**：结合身体活动指南，避免久坐
- **科普风格**：说人话、给具象量、指误区——精准但不端着

## 关键数据速查

| 项目 | 推荐量 | 通俗理解 |
|------|--------|---------|
| 超重判定 | BMI≥同年龄同性别第85百分位 | 超重了，要注意 |
| 肥胖判定 | BMI≥同年龄同性别第95百分位 | 需要干预 |
| 屏幕时间（2-5岁） | ≤1小时/天 | 少看手机多运动 |
| 屏幕时间（6-17岁） | ≤2小时/天 | 作业间隙也要动一动 |
| 运动（学龄儿童） | ≥60min/天中高强度 | 体育课+课间活动就够了 |
| 含糖饮料 | 不喝或少喝 | 一瓶可乐≈半碗饭的热量 |
| 减重速度 | 0.5-1kg/月（超重肥胖） | 别急，孩子在长个子 |

## 适用范围

- **适用对象**：基层卫生工作者（含营养指导人员）、2~17岁儿童青少年家长、校医
- **适用情境**：以饮食营养为主的儿童青少年单纯性肥胖的预防、控制和日常食养指导
- **注意事项**：由内分泌、遗传、神经系统等疾病引起的继发性肥胖，需先就医诊断
